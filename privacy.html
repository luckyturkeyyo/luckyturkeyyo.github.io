JIMIN CORE 개인정보처리방침

시행일: 2026-11-17

JIMIN CORE(이하 "앱")는 운영자 본인의 YouTube 채널과 Google Drive 데이터를 관리·분석하기 위한 내부용 도구입니다.

  • 수집하는 정보: 운영자가 승인한 범위 내의 YouTube 채널·영상 통계(조회수, 시청 지속시간, 트래픽 소스 등)와 Google Drive 업무 파일
  • 이용 목적: 콘텐츠 성과 분석과 업무 자동화
  • 제3자 제공: 하지 않습니다.
  • 보관과 삭제: 운영자 본인 PC에만 저장되며, 운영자가 언제든 삭제할 수 있습니다.
  • 권한 철회: https://myaccount.google.com/permissions 에서 언제든 철회할 수 있습니다.
  • Google API 사용자 데이터 정책: 앱의 Google API 데이터 사용은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다.
  • 문의: luckyturkeyyo@gmail.com

Privacy Policy (English)

JIMIN CORE is an internal tool used only by its operator to manage and analyze the operator's own YouTube channels and Google Drive files. It accesses only data the operator authorizes (YouTube channel/video statistics and Drive work files), uses it solely for content analytics and workflow automation, does not share it with third parties, and stores it only on the operator's own computer. Access can be revoked at any time at https://myaccount.google.com/permissions. Use of Google API data complies with the Google API Services User Data Policy, including the Limited Use requirements.
